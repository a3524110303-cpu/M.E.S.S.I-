# Fuentes del equipo

Las copias de documentos se conservan intactas. El documento del proyecto MESSI
01 guía la base de la primera entrega. Las demás plantillas describen requisitos
de entregas futuras; sus filas de ejemplo no son evidencia del proyecto.

La ficha MESSI del Bloque 1 Parte II, localizada en Descargas, documenta los
roles que el equipo confirmó conservar. Su bitácora histórica no se modifica.
El PDF de diseño arquitectónico propone una evolución con microservicios y se
mantiene como referencia; esa arquitectura no está implementada en este
esqueleto Streamlit.

El archivo 06 adjunto es una plantilla. La bitácora completada que el equipo
indica tener deberá incorporarse cuando se cuente con ese archivo, sin alterar
su contenido original.
